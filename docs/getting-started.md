# Getting Started

## Prerequisites

- **Node.js ≥ 22** (repo tested on 24)
- **pnpm ≥ 11** — `corepack enable && corepack prepare pnpm@latest --activate`
- **.NET SDK 10**
- For mobile: Xcode (iOS simulator) and/or Android Studio, or the Expo Go app on a physical device

## Install

```bash
pnpm install                 # all JS workspace packages
dotnet build apps/api/Sona.slnx   # restore + build the API
```

> The repo's `.npmrc` sets `node-linker=hoisted` (required by Expo) and `pnpm-workspace.yaml` pins `lightningcss` (required by NativeWind). Don't remove either.

## Environment

Each frontend reads its API base URL from an env file (both default to `http://localhost:5032`):

```bash
cp apps/admin/.env.example apps/admin/.env
cp apps/mobile/.env.example apps/mobile/.env
```

For mobile on a **physical device**, replace `localhost` with your machine's LAN IP.

## Run

```bash
# API (terminal 1) → http://localhost:5032
dotnet run --project apps/api/Sona.Api

# Web admin (terminal 2) → http://localhost:5173
pnpm dev:admin

# Mobile (terminal 3) — press i for iOS simulator, a for Android
pnpm dev:mobile
```

## Verify

```bash
pnpm typecheck    # TS across all workspace packages
pnpm build        # production builds
pnpm lint
```

## Gotchas

- **Route tree generation (admin):** `src/app/routeTree.gen.ts` is generated by the TanStack Router Vite plugin when `vite dev`/`vite build` runs. On a fresh clone, run `pnpm dev:admin` or `pnpm build` once before `typecheck`.
- **`expo-env.d.ts` (mobile):** auto-generated by Expo; committed so typecheck works without starting the dev server first.
- **Adding mobile native deps:** use `npx expo install <pkg>` (not `pnpm add`) inside `apps/mobile` so versions match the SDK.
